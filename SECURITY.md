# Security Policy

HiringFleet handles resumes, contact details, and immigration timelines. We take the security of that data seriously, and we appreciate anyone who reports a weakness responsibly.

## Reporting a vulnerability

Email **[support@hiringfleet.com](mailto:support@hiringfleet.com)** with the subject line `Security report`.

Please include:

- A description of the issue and where you found it (URL or endpoint)
- Steps to reproduce it
- What you believe the impact is

We'll acknowledge your report within 3 business days and keep you updated as we investigate and fix it.

## Please don't

- Access, modify, or delete data that isn't yours — use a test account and stop at proof of concept
- Run automated scanners or load tests against production
- Publicly disclose an issue before we've had a reasonable chance to fix it

We don't run a paid bounty program today, but we credit reporters who want to be named once a fix ships.
